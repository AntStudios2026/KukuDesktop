# 🐣 KuKuDesktop

Un entorno seguro y divertido para niños pequeños donde podrán jugar, leer y explorar de manera tranquila en la computadora.

---

Haz clic en el siguiente botón para ir a la última versión publicada y descargar el archivo comprimido (`.zip`):

---

## 🚀 Cómo instalar y ejecutar

1. Descarga el archivo `.zip` desde el enlace de arriba.
2. Haz clic derecho sobre el archivo descargado y selecciona **Extraer todo...** (es importante descomprimirlo)
3. Abre la carpeta extraída y haz doble clic en **`KuKuDesktop.exe`**.

> **🔑 Contraseña predeterminada:** `1234` (necesaria para acceder a los ajustes o salir del modo infantil).
